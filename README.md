# ДТЕК: Світло є

Піксельна гра для Android про оборону енергосистеми Києва: tower defense, симулятор мережі й менеджмент ремонту. Неофіційна фан-гра, не пов'язана з ДТЕК, Укренерго чи іншими компаніями.

Удень бригади ремонтують, ви будуєте, укріплюєте й закуповуєте. Уночі — повітряна тривога: шахеди й ракети летять на ТЕЦ, підстанції, ГЕС. Не дайте Києву зануритися в повну темряву.

## Встановлення

1. Завантажте `release/DTEK-Svitlo-Ye-1.2.0.apk` на телефон (Android 7.0+).
2. Дозвольте встановлення з невідомих джерел для браузера або файлового менеджера.
3. Відкрийте APK і встановіть. Гра працює повністю офлайн.

## Що нового у 1.2

- **Фонова музика:** спокійний трек удень і тривожний під час атаки, плавний перехід. Окремий перемикач і гучність у налаштуваннях та меню паузи. Джерело — OpenGameArt, CC0.
- **Читабельний шрифт:** інтерфейс і підписи на мапі тепер шрифтом Rubik. Піксельний Pixelify Sans лишився тільки в логотипі.
- **Графіки відключень за наказом Укренерго** (вкладка «Графіки»):
  - наказ приходить у МВт: «Київ споживає не більше X МВт до HH:00»;
  - автомат або ручний графік: черги з 6 для всього Києва одразу або окремо по районах;
  - «Підібрати під ліміт» складає мінімальний графік, пріоритетні райони отримують на 2 черги менше;
  - можна вимкнути промзони, щоб зберегти світло побуту;
  - перевищили ліміт — Укренерго застосовує ГАВ (аварійні відключення злять утричі сильніше) і штраф 2 млн за годину;
  - наказ закінчився — ручний графік знімається сам.
- **Екстрені відключення районів:** миттєво знеструмлюють район, а водоканал і метро на окремих фідерах працюють. Довіра падає як за аварійне відключення, але під час тривоги вдвічі менше, а пожежі на знеструмлених підстанціях горять слабше.

## Що нового у 1.1

- **Метро:** три лінії (M1–M3), 52 станції за координатами OSM. Поїзди їздять, лише коли район під лінією має світло; зупинене метро злить киян.
- **Справжні вулиці й шосе:** дороги, мости, залізниці, озера, затоки, парки та промзони Києва з OpenStreetMap. Ліхтарі на проспектах гаснуть у блекаут.
- **Нові об'єкти:**
  - промзони з бізнес-тарифом (у дефіцит їх гасять першими, або можна дати їм пріоритет);
  - сміттєспалювальний завод «Енергія» (тепло Позняками);
  - вітряки за містом, які треба підключати ЛЕП.
- **Записані звуки:** сирена, вибухи, кулемети, «Гепард», пуски, «мопед» шахедів, відбій. Джерело — OpenGameArt, CC0.
- **Час як у Hearts of Iron:**
  - на швидкості 1 одна хвилина дорівнює одній годині гри;
  - швидкості 1–5, пауза, клавіші 1–5 і пробіл;
  - автопауза на початку тривоги.

## Що всередині

- Мапа Києва з полігонів районів OpenStreetMap: Дніпро, острови, мости, ~3500 будинків, вікна яких світяться, лише коли в районі є світло. Черги відключень гасять будинки групами.
- Реальні об'єкти з відкритих джерел (цифри округлені, розташування умовне):
  - ТЕЦ-5, ТЕЦ-6, Дарницька ТЕЦ;
  - Київська ГЕС і ГАЕС, Трипільська ТЕС;
  - ПС 750 кВ «Київська», кільце 330 кВ;
  - ПС 110 кВ (назви умовні), критичні споживачі (водоканал, метро).
- Мережа рахується як потік мінімальної вартості з 6 чергами на район: дефіцит ділиться чесно. Локальна генерація працює острівно.
- 9 типів загроз:
  - Шахед, Гербера-імітатор, реактивний шахед, розвідник;
  - Х-101, Калібр;
  - Іскандер, Кинджал, Циркон.
- 9 типів ППО і патруль F-16:
  - МВГ з прожекторами, ПЗРК, «Гепард», дрони-перехоплювачі, РЕБ, РЛС;
  - NASAMS, IRIS-T, Patriot.
  - У ЗРК є політика вогню.
- Захист Р1–Р3, три типи бригад з утомою та пораненнями від повторних ударів, трансформатори, проєкти відновлення.
- Економіка (тариф, паливо, імпорт, гранти, компенсації), довіра киян, тепло взимку, Пункти незламності, ліміти Укренерго.
- Кампанія «Хроніка 2022–2026» (10 глав), безкінечна оборона, 4 складності, 17 технологій, випадкові події, стрічка новин.
- Процедурний звук: сирена, «мопед» шахедів, кулемети, вибухи, гул генераторів у темних районах.

## Розробка

```bash
npm ci
npm run dev          # http://localhost:5173
npm test             # юніт-тести (vitest)
npm run balance      # бот-балансер: npx vite-node tools/balance.ts all 3
node tools/e2e.mjs   # E2E-скриншоти через Playwright (потрібен запущений dev-сервер)
npm run build        # dist/index.html — усе в одному файлі
```

### Збірка APK

Потрібні JDK 17+, Gradle 8.x і Android SDK (`platforms;android-35`, `build-tools;35.0.0`).

```bash
export ANDROID_HOME=/шлях/до/android-sdk
./tools/build-apk.sh   # → release/DTEK-Svitlo-Ye-<версія>.apk
```

`android/` — мінімальна WebView-обгортка на Java без AndroidX. Ключ підпису лежить в `android/keystore/`, щоб нові версії ставилися поверх старих без втрати збережень. Якщо репозиторій публічний, ключ теж публічний. Для хобі-гри це прийнятно, для публікації в Google Play — ні.

### Структура

- `src/sim` — симуляція без DOM: мережа, бій, бригади, економіка, події, хвилі, бот.
- `src/render` — Canvas-рендер, спрайти, мапа.
- `src/ui` — HTML-інтерфейс.
- `src/data` — геодані, об'єкти, характеристики, баланс, глави.
- `docs/GAME_DESIGN.md` — дизайн-документ і джерела.
