# Раскоп

Копательный кликер для телефона: тапаешь по блоку, копаешь вглубь, нанимаешь помощников,
находишь артефакты и начинаешь новые шахты. Один HTML-файл, без зависимостей и сети.

## Запуск

Открой `index.html` в браузере. Прогресс сохраняется в `localStorage`.

## Что внутри

- 14 слоёв породы (Дёрн → Пустота), у каждого свой цвет интерфейса
- 12 инструментов, 12 помощников, 5 прокачек, 70 находок, 27 наград
- «Новая шахта» (престиж) с лавкой самоцветов
- Оффлайн-копка, золотые жилы (случайные бонусы), удержание пальца для автотапа
- Режим экономии батареи в «Ещё → Настройки»
- Экспорт и импорт сохранения кодом
